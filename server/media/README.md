# Wellbeing media folder

Jurors see every audio file in this folder in **Wellbeing → Listen**. Files are
streamed from the court laptop over the LAN; nothing is downloaded from the internet.

## Adding licensed audiobooks or music

1. Get audio the court is licensed to play to jurors (library audiobooks, purchased
   music, public-domain recordings). **Do not add copyrighted audio without a licence.**
2. Copy the files into this folder (`server/media/`). Supported formats:
   `.mp3`, `.m4a`, `.ogg`, `.wav`, `.flac`.
3. Optional: describe each file in `catalog.json` so jurors see a proper title:

   ```json
   [
     { "file": "pride-and-prejudice-ch1.mp3", "title": "Pride and Prejudice, Chapter 1",
       "creator": "Jane Austen (read by …)", "kind": "audiobook", "description": "" }
   ]
   ```

   `kind` is `audiobook`, `music` or `ambient`. Files without an entry still appear,
   titled from their filename.
4. No restart is needed. Jurors see the new tracks the next time they open the page.

The `placeholder-*.wav` files are simple tones generated by `npm run seed`. They
contain no copyrighted material, and you can delete them.
